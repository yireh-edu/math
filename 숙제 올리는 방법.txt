이레 수학 숙제 · 숙제 올리는 방법

[폴더 구성]
  current.js     ← 숙제 파일. 이 파일만 고쳐서 올리면 숙제가 바뀝니다.
  images/        ← 문제에 넣을 그림 (선택)
  index.html, assets/, icons/, manifest.webmanifest, sw.js   ← 앱 파일 (고치지 마세요)

[새 숙제를 낼 때]
  1. current.js를 메모장이나 VS Code로 엽니다.
  2. 숙제의 id를 새 이름으로 바꿉니다. (예: '2026-10-05-중2수학')
     id가 바뀌면 학생들의 기록이 새로 시작됩니다. 같은 숙제를 고치기만 할 때는 id를 그대로 두세요.
  3. title(제목), due(마감일), note(안내), questions(문제)를 바꿉니다.
     문제 쓰는 형식은 파일 맨 위 설명에 있습니다.
  4. 저장한 뒤 GitHub 저장소에 current.js를 올리면 끝입니다.
     학생 화면에는 열 때마다 새로 받아서 바로 반영됩니다.

[반마다 다른 숙제]
  sets 안에 숙제를 여러 개 넣으면 학생이 위쪽 버튼으로 골라서 풉니다.

[그림 넣기]
  그림 파일을 images 폴더에 올리고, 문제에 img: 'images/파일이름.png' 를 추가합니다.

[학생 결과 받기]
  학생이 다 풀면 제출 화면에 보내는 방법이 나옵니다.
    1. 이름 적기
    2. [카톡으로 보내기] → 휴대폰 공유 목록에서 카카오톡 → 선생님(또는 반 단톡방) 골라 보내기
    3. 카톡이 목록에 없으면(PC 등) [결과 복사] → 카톡 선생님 채팅방에 붙여넣기
  학생에게 '선생님 개인톡으로 보낼지, 반 단톡방에 올릴지' 미리 알려 주세요.
  서버가 없어서 선생님이 자동으로 모아 볼 수는 없습니다.
  서술형은 학생이 정답을 보고 스스로 채점한 결과입니다.

[학생 기록 백업]
  기록은 학생 휴대폰(브라우저)에만 저장됩니다. 화면 맨 아래 [기록 백업 · 옮기기]에서
  백업 코드를 복사해 카톡 '나와의 채팅'에 보관하고, 새 휴대폰에서 붙여 넣으면 이어서 쓸 수 있습니다.
  (같은 github.io 주소의 세 앱 기록이 한 번에 저장됩니다)

[주의]
  - 쉼표(,)와 따옴표 짝이 맞지 않으면 숙제가 안 보입니다.
    안 보이면 고친 부분을 다시 확인하거나 Claude에게 파일을 보여 주세요.
  - 수식은 r`...` 안에 쓰면 역슬래시를 하나만 써도 됩니다. (예: r`$\frac{1}{2}$`)
  - 로컬 LLM에게 문제를 만들게 할 때는 파일 맨 위 형식 설명과 기존 문제 2~3개를 함께 붙여 넣으세요.
